## ❓ Analysis & Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services with over 200 fully featured options spanning compute, storage, databases, IoT, and edge computing. As the pioneer of public cloud computing launched in 2006, AWS has built the most mature and expansive global infrastructure ecosystem. Its extensive market presence provides unparalleled breadth and third-party tooling integration compared to competitors.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best native integration for organizations using Microsoft technologies like Windows Server, Active Directory, and SQL Server. Azure allows enterprises to seamlessly extend on-premises Active Directory environments to the cloud using Microsoft Entra ID. Additionally, Azure offers cost savings through Hybrid Benefit licensing discounts for existing Windows software.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) leads in Artificial Intelligence, Machine Learning, and Kubernetes services. Because Google originally developed Kubernetes internally before open-sourcing it, Google Kubernetes Engine (GKE) remains the most advanced managed Kubernetes service available. GCP also offers industry-leading AI infrastructure through Vertex AI and specialized TPU hardware accelerators.

### 4. Which cloud platform would you personally choose and why?
I would personally choose Google Cloud Platform (GCP) due to its user-friendly console interface and superior native containerization support. GCP's high-speed global fiber network and advanced BigQuery analytics engine make it an exceptional environment for modern software development. Its innovative suite of tools provides a streamlined developer workflow without unnecessary configuration overhead.
