# ☁️ Cloud Platform Recommendation Challenge

---

## 📌 Client Scenario Recommendations

### Client A – Startup Company
* **Recommended Cloud Platform:** Amazon Web Services (AWS)
* **Recommendation Explanation:**
  Amazon Web Services (AWS) is the ideal platform for a growing startup due to its unmatched elasticity, massive global ecosystem, and flexible pay-as-you-go pricing model. The AWS Free Tier and AWS Activate program provide financial relief for early-stage startups with limited budgets. AWS enables the startup to scale seamless compute resources automatically as user adoption explodes over the coming years without requiring upfront infrastructure investments.
* **Recommended Services:**
  1. **Amazon EC2:** For scalable virtual server hosting.
  2. **Amazon S3:** For cost-effective user media and asset storage.
  3. **Amazon DynamoDB:** A fully managed NoSQL database built for rapid scaling.

---

### Client B – University
* **Recommended Cloud Platform:** Microsoft Azure
* **Recommendation Explanation:**
  Microsoft Azure is the best recommendation for the university because of its native alignment with Windows Server, Active Directory, and Microsoft 365. Migrating on-premises Active Directory to Microsoft Entra ID provides unified single sign-on across campus infrastructure without architectural friction. Furthermore, Azure Hybrid Benefit allows the university to reuse existing Windows software licenses to significantly reduce cloud operational expenditures.
* **Recommended Services:**
  1. **Microsoft Entra ID (Azure AD):** For centralized campus identity and single sign-on management.
  2. **Azure Virtual Machines:** To migrate legacy Windows Server workloads to the cloud seamlessly.
  3. **Azure SQL Database:** For hosted relational academic and database infrastructure.

---

### Client C – AI Research Company
* **Recommended Cloud Platform:** Google Cloud Platform (GCP)
* **Recommendation Explanation:**
  Google Cloud Platform provides industry-leading infrastructure custom-built for high-performance computing, artificial intelligence, and machine learning workloads. GCP features specialized Tensor Processing Units (TPUs) and state-of-the-art managed AI platforms that significantly accelerate model training and deployment. Its underlying high-speed global fiber network ensures low-latency data throughput required for intensive AI research tasks.
* **Recommended Services:**
  1. **Vertex AI:** A unified platform to build, deploy, and scale machine learning models.
  2. **Google Cloud Storage (GCS):** High-throughput object storage for training datasets.
  3. **Google Compute Engine (GCE with Cloud TPUs):** High-performance TPU/GPU compute instances for model training.

---

### Client D – Global E-Commerce Company
* **Recommended Cloud Platform:** Amazon Web Services (AWS)
* **Recommendation Explanation:**
  AWS offers the most mature global infrastructure footprint required to deliver zero-downtime, highly available e-commerce applications to international customers. AWS Auto Scaling automatically manages flash-sale traffic spikes, while global content delivery networks minimize latency for end users worldwide. Its comprehensive security controls and multi-region deployment features guarantee resilience against regional datacenter outages.
* **Recommended Services:**
  1. **Amazon CloudFront:** Global Content Delivery Network (CDN) for fast asset delivery.
  2. **Amazon Aurora:** High-performance managed relational database with automated global replication.
  3. **AWS Auto Scaling:** Automatically adjusts compute capacity based on incoming customer demand.
