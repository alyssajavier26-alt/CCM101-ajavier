### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/book-16.svg" width="20" height="20" /> Executive Reflection

Object storage is far better suited for storing millions of user photos than traditional block storage because its flat namespace scales infinitely without the file-system overhead or performance degradation associated with traditional directory trees. Deploying the MinIO storage server with Docker simplified the process by bundling all service dependencies into a portable, isolated environment that launched consistently with a single command. In object storage, a "bucket" serves as a logical flat container designed to organize objects (files) and associate custom metadata without rigid directory hierarchies. To prevent data loss if a physical server crashes, large enterprise organizations use features like automated multi-node replication, erasure coding, and geo-redundant backups across isolated data availability zones. Through this hands-on activity, my confidence in navigating the Linux command line has grown significantly, especially in managing containerized deployments, configuring environment variables, and troubleshooting remote cloud infrastructure seamlessly.
