### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/info-16.svg" width="20" height="20" /> Mission Overview

Congratulations! Your seamless deployment of containerized web servers caught the attention of the senior architects, leading to a temporary reassignment to the **Cloud Data Engineering Team at CloudNova Technologies**.

In the cloud, data is everything, but not all data is stored the same way. While traditional computers use hard drives (Block Storage) and shared network drives (File Storage), modern cloud applications rely heavily on **Object Storage** to store massive amounts of unstructured data like images, videos, and backups. In this mission, an open-source S3-compatible cloud storage server (**MinIO**) was deployed using Docker to create storage buckets and manage file uploads over the web.

---

### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/checklist-16.svg" width="20" height="20" /> Objectives

* Differentiate between **Block**, **File**, and **Object Storage**.
* Deploy an S3-compatible Object Storage server (**MinIO**) using Docker.
* Access cloud services via a web interface using port forwarding (`9001`).
* Create a storage bucket (`client-photos`) and upload objects (files) to the cloud.
* Document cloud storage operations using structured Markdown.
* Continue expanding a professional GitHub Cloud Computing Portfolio.
