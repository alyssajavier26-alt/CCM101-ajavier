### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/comment-discussion-16.svg" width="20" height="20" /> Mission Reflection

A host-based firewall acts as a critical line of defense because it protects an individual server even if the physical or cloud network perimeter is breached. If an attacker manages to bypass cloud virtual private cloud (VPC) security groups or external network perimeter controls, the internal host-based firewall still enforces strict rules, preventing unauthorized lateral movement. Managing open network ports is equally vital to reducing a server's attack surface; every open port represents a potential entry point for attackers and automated vulnerability scanners. Leaving sensitive database ports, such as MySQL port 3306, open to the public internet in an enterprise environment invites catastrophic data breaches, as unauthorized actors can launch brute-force attacks or exploit unpatched database vulnerabilities. Completing this mission fundamentally transformed my perspective on server security, revealing just how vulnerable a newly deployed machine is within seconds of connecting to the internet and highlighting the absolute necessity of proactive defense-in-depth engineering. Looking across my entire GitHub portfolio from Laboratory 1 to Laboratory 8, my understanding of cloud computing has evolved profoundly from basic conceptual navigation to hands-on infrastructure provisioning, containerization, and active security hardening. Among all the roles explored this semester, I enjoyed the Cloud Security Engineer role the most because implementing strict firewalls, enforcing least privilege, and actively neutralizing exposure risks provided an immediate, highly rewarding sense of protecting digital assets against threats.
