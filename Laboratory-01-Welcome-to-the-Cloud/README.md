# Laboratory Activity 1: Mission 1 - Welcome to the Cloud

## Mission Overview
Brief overview of the onboarding activity at CloudNova Technologies, setting up the KillerCoda Linux environment, and initializing the cloud computing portfolio on GitHub.

## Objectives
* Access a cloud-based Linux environment using KillerCoda.
* Navigate and gather system information using Linux commands.
* Build directory structures and manage files via CLI.
* Create and structure a professional GitHub repository.

## Activities Performed
* Provisioned an Ubuntu 24.04 environment on KillerCoda.
* Created a custom user account with sudo privileges.
* Collected kernel, CPU, RAM, and disk utilization data.
* Built local folder structures (Documents, Notes, Reports, Screenshots).
* Cloned and structured the GitHub portfolio repository.

## Linux Commands Used
adduser, usermod, su, whoami, pwd, hostname, cat, uname, lscpu, free, df, mkdir, nano, ls, cp, git

## Skills Learned
* Basic Linux system administration and user management.
* System resource inspection and command-line navigation.
* Markdown documentation practices.
* Version control workflows using Git and GitHub.
