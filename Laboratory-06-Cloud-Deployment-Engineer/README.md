### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/terminal-16.svg" width="20" height="20" /> Commands Executed

| Command | Purpose |
| :--- | :--- |
| `nano docker-compose.yml` | Opens the terminal text editor to write multi-container YAML configurations. |
| `docker-compose up -d` | Deploys the multi-tier application stack in the background. |
| `docker-compose ps` | Verifies that all containers in the stack are actively running. |
| `docker-compose down` | Gracefully stops and removes the containerized infrastructure. |
