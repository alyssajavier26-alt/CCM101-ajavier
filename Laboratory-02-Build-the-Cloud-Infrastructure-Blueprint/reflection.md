# 💭 Mission Reflection

Completing this cloud infrastructure mission provided vital hands-on experience in investigating, profiling, and mapping virtual server environments. Throughout the laboratory activity, I gained a deep practical understanding of how core components—such as compute processing, storage volumes, networking interfaces, and operating system kernels—interact inside a live Linux cloud server. By using command-line diagnostic tools like `lscpu`, `free -h`, `df -h`, and `ip addr`, I successfully extracted baseline hardware specs and internal network configurations, which helped me analyze server capacity for future app deployments. Comparing major public cloud providers like AWS, Azure, and GCP highlighted how equivalent infrastructure services operate across different vendor platforms under unique naming conventions. The most challenging aspect of this activity was distinguishing private container network interfaces from host-level virtual adapters, but analyzing output from IP routing utilities alongside system hostnames clearly resolved the network hierarchy. Overall, this assessment strengthened my technical documentation skills in Markdown and built a solid foundation for designing real-world, highly available cloud architecture blueprints.
