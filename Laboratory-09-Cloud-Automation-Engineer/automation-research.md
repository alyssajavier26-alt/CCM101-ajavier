### <img src="https://raw.githubusercontent.com/primer/octicons/main/icons/book-16.svg" width="20" height="20" /> Core Automation Concepts

#### 1. Bash Script
A Bash script is a plain-text file containing a series of shell commands that the Linux command line executes sequentially to automate repetitive tasks. The `#!/bin/bash` line at the very top is known as a shebang, which explicitly tells the operating system which interpreter (Bash) should be used to execute the commands contained within the file.

#### 2. Variables
Programmers use variables (such as `$BACKUP_DIR`) to store dynamic values, configuration paths, or data so they can be referenced and modified centrally throughout a script. This practice eliminates the need to hardcode paths repeatedly, making the code much easier to maintain, update, and reuse.

#### 3. Cron Job
A cron job is a time-based task scheduler in Linux that automatically runs scripts or commands at specified intervals, dates, or times. It is essential for cloud operations because it eliminates human error and manual labor by ensuring critical recurring tasks like system backups execute reliably without manual intervention.
